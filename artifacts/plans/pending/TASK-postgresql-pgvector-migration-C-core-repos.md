# Task: Domain Repositories — Core

## Problem Statement

Nomarr is migrating from ArangoDB to PostgreSQL 17 + pgvector. Parts A and B established SQLAlchemy ORM models, the async engine, and SQL primitives (`select_by_key`, `upsert_by_field`, etc.). Part C creates the Tier 2 domain repository classes that replace the six core ArangoDB AQL operation packages. Each repository receives an `AsyncSession`, uses Part B primitives for basic CRUD, and uses direct SQLAlchemy queries for domain-specific operations. Repos return TypedDicts — never raw SQLAlchemy model instances across the layer boundary.

**Prerequisite:** TASK-postgresql-pgvector-migration-A (models, engine) and TASK-postgresql-pgvector-migration-B (SQL primitives).

Scope:
- Replace `libraries_aql.py` → `library_repo.py`
- Replace `library_files_aql/` → `file_repo.py` + `folder_repo.py`
- Replace `tags_aql/` → `tag_repo.py`
- Replace `scan_aql.py` → `scan_repo.py`
- Replace `app_aql/` → `app_repo.py`
- Replace `app_aql/pipeline_state_ops.py` → `pipeline_repo.py`
- Create `file_state_repo.py` (FileStateRepository — was missing, flagged as BLOCKING by Plan E)
- Define persistence-layer TypedDicts for repo return types (in `nomarr/helpers/dto/` per architecture conventions)
- DO NOT modify existing `aql/` files — that is Part F

Out of scope: ML/Navidrome repos (Part D), intent facade adaptation (Part E), tests (Part G).

- [ ] Create `nomarr/persistence/database/library_repo.py` with `LibraryRepository` class. Constructor takes `AsyncSession`. Methods: `add_library(payload) -> int`, `get_library(library_id) -> LibraryRow | None`, `get_library_by_name(name) -> LibraryRow | None`, `list_libraries(*, enabled_only: bool = False) -> list[LibraryRow]`, `list_library_keys() -> list[int]`, `update_library(library_id, fields) -> None`, `delete_library(library_id) -> None`, `update_pipeline_axis(library_id, axis_field, axis_value) -> None`, `get_pipeline_state(library_id) -> dict[str, str] | None`, `get_libraries_in_axis_state(axis_field, axis_value) -> list[int]`, `remove_library(library_id) -> None`. The `remove_library` method uses `await session.delete(library)` + `await session.commit()` — FK ON DELETE CASCADE handles all child data (replaces 147-line AQL cascade). Uses `select_by_key`, `insert_one`, `update_by_field`, `delete_by_key` from Part B primitives for simple ops.
- [ ] Create `nomarr/persistence/database/file_repo.py` with `FileRepository` class. Constructor takes `AsyncSession`. Methods: `add_file(payload) -> int`, `get_file(file_id) -> LibraryFileRow | None`, `get_file_by_path(path, library_id) -> LibraryFileRow | None`, `get_file_by_path_unscoped(path) -> LibraryFileRow | None`, `get_file_by_normalized_path(library_id, normalized_path) -> LibraryFileRow | None`, `upsert_file(payload) -> int`, `upsert_files_for_library(library_id, payloads) -> list[int]`, `update_file(file_id, fields) -> None`, `delete_file(file_id) -> None`, `list_files(*, filters, limit) -> list[LibraryFileRow]`, `count_files() -> int`, `get_files_by_ids(file_ids) -> list[LibraryFileRow]`, `get_library_ids_for_files(file_ids) -> dict[int, int]`, `list_library_file_ids(library_id, *, limit) -> list[int]`, `list_library_files(library_id, *, limit) -> list[LibraryFileRow]`, `list_existing_file_paths(paths) -> list[str]`, `find_by_chromaprint(library_id, chromaprint) -> LibraryFileRow | None`, `list_files_for_folder(library_id, folder_rel_path) -> list[LibraryFileRow]`, `remove_files(file_ids) -> None`. Replaces `library_contains_file` edge traversals with simple `library_id` FK column queries. `remove_files` uses `await session.execute(delete(LibraryFile).where(LibraryFile.id.in_(file_ids)))` — CASCADE handles derived data. Maintenance methods: `list_orphaned_file_ids() -> list[int]` (returns file IDs with no matching library — LEFT JOIN on libraries), `truncate_files() -> None` (DELETE FROM library_files), `truncate_file_links() -> None` (DELETE FROM file_tags).
- [ ] Create `nomarr/persistence/database/folder_repo.py` with `FolderRepository` class. Constructor takes `AsyncSession`. Methods: `add_folder(payload) -> int`, `add_library_folder(library_id, payload) -> int`, `get_folder(folder_id) -> LibraryFolderRow | None`, `get_folder_by_path(library_id, path) -> LibraryFolderRow | None`, `list_folders_for_library(library_id) -> list[LibraryFolderRow]`, `get_root_folders(library_id) -> list[LibraryFolderRow]`, `get_by_parent(library_id, parent_id) -> list[LibraryFolderRow]`, `remove_library_folder(library_id, folder_id) -> None`, `replace_library_folders(library_id, payloads) -> None`. Replaces `folder_has_folder` edge traversals with `parent_id` self-reference FK and `library_has_folder` edges with `library_id` FK column. Maintenance methods: `truncate_folders() -> None` (DELETE FROM library_folders), `truncate_folder_links() -> None` (clears folder relationship data if any junction table exists).
- [ ] Create `nomarr/persistence/database/scan_repo.py` with `ScanRepository` class. Constructor takes `AsyncSession`. Methods: `create_scan(payload) -> int`, `get_scan_record(library_id) -> LibraryScanRow | None`, `update_scan(scan_id, fields) -> None`, `delete_scan_record(scan_id) -> None`. Simple CRUD — uses Part B primitives directly. Replaces `library_has_scan` edge with `library_id` FK column. Maintenance method: `truncate_scans() -> None` (DELETE FROM library_scans).

Replaces `song_has_tags` edge collection with `file_tags` junction table JOINs. `file_has_tag` edge attributes (confidence, source) stored as columns on junction table. `get_tags_for_file` uses `SELECT tags.* FROM tags JOIN file_tags ON tags.id = file_tags.tag_id WHERE file_tags.file_id = :file_id`. `get_or_create_tag` uses `upsert_by_field` on `(name, value, namespace)` unique constraint. Additional methods for Plan E facade support: `search_files_by_tag_contains(query: str, limit: int = 100) -> list[int]` (LIKE/%query%/file_ids via file_tags JOIN), `list_all_tag_names() -> list[str]` (SELECT DISTINCT name FROM tags), `count_tags_filtered(namespace: str | None = None, category: str | None = None) -> int` (COUNT with optional filters), `list_tags_with_song_count(min_count: int = 0) -> list[dict]` (tags LEFT JOIN file_tags GROUP BY with HAVING count >= min_count), `get_genre_tags_for_files(file_ids: list[int]) -> dict[int, list[str]]` (batch genre tag lookup grouped by file_id), `search_files_by_tag_pattern(pattern: str, limit: int = 100) -> list[int]` (pg_trgm similarity match on tag name, returns file_ids).
